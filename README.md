# نظام إدارة النتائج – Results Management System

تطبيق ويب تفاعلي (التكليف العملي 3 – المشروع النهائي) لتسجيل درجات الطلاب والتحقق من صحة البيانات وتفعيل «لجنة الرأفة».

## التقنيات
- HTML5
- Bootstrap 5 (RTL) عبر CDN
- JavaScript (ES2022): Classes، Private Fields (`#`)، getters/setters، `try/catch`، DOM، `filter` / `map` / `reduce`، Template Literals

## هيكل المشروع
```
results-management-system/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## طريقة التشغيل
افتح `index.html` في المتصفح (يحتاج اتصالاً بالإنترنت لتحميل Bootstrap).

## المميزات
- **حارس الأمان:** كلاس `Student` يحمي الدرجات ونسبة الحضور بحقول خاصة و`set` ترمي `throw new Error(...)` إذا كانت القيمة فارغة أو غير رقمية أو أقل من 0 أو أكبر من 100.
- **اصطياد الأخطاء:** تظهر رسالة الخطأ باللون الأحمر على الشاشة (وليس في الكونسول) ولا ينهار التطبيق.
- **قائمة الطلاب:** جدول يعرض الاسم والدرجات والمتوسط والحضور والحالة.
- **لجنة الرأفة:**
  - `filter`: الطلاب الذين متوسطهم من 40 إلى أقل من 50.
  - `map`: إضافة 5 درجات لمتوسط كل طالب.
  - `reduce`: حساب المتوسط العام بعد الرأفة مع منع القسمة على صفر.
  - تقرير نهائي (العدد، الأسماء، المتوسط العام) مبني بقوالب النصوص.
- حماية من حقن HTML في الأسماء، وتصميم متجاوب للهاتف والتابلت والكمبيوتر.

## ملاحظة
شرط «المتوسط بين 40 و49» طُبّق كـ `40 ≤ المتوسط < 50` حتى لا يسقط طالب متوسطه 49.5 من اللجنة.
